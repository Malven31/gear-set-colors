# Changelog

Each version has a section `## <version> (<date>)` summarising, for players, what is new (`### New`), fixed (`### Fixed`) and changed (`### Changed`). That section, and only that section, is sent to CurseForge as the changelog of the version's file, so it shows on the website and in the CurseForge app. A beta (`1.1.0-beta1`) uses its own section if it has one, otherwise the section of its final version (`1.1.0`). The full feature list is in FEATURES.md.

## 1.0.0 (2026-11-18)

First public release of Gear Set Colors, for World of Warcraft: Forever.

### New

- Items in your bags that belong to an equipment set are marked with that set's colour, so you don't sell them by mistake.
- Three ways to mark them, to mix as you like: a coloured border and a coloured tint (both on by default), and a small square per set in the corner.
- An item in several sets shows all their colours: its border alternates between them, and it gets one corner square per set.
- Every set gets its own colour by itself. Change it, or stop marking a set, in Options > AddOns > Gear Set Colors (`/gsc`).
- A colour square on each set in the Character window's Equipment Manager: click it to change that set's colour.
- Colours go by set name and are shared by all your characters.
