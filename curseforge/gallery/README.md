# Gallery

Screenshots for the CurseForge gallery go in this folder.

`private/` is ignored by git. It keeps the originals that don't belong in the repository: captures too large to commit, and screenshots showing a character name. CurseForge shows each image with a title and a description, so each shot below has both ready to paste.

To show one in the description or the README, commit it here and load it in the description from `https://raw.githubusercontent.com/Malven31/gear-set-colors/main/curseforge/gallery/<file>` (the README uses the relative path). That needs the repository to stay public.

## Screenshots

Tips:

- Take them with the in-game screenshot key (Print Screen). They are saved in `_forever_\Screenshots`.
- Crop to the bags or the window shown: no character names, no chat, no player frame.
- Two or three equipment sets with clearly different colours make the point best, with a few ordinary items (potions, reagents, grey junk) unmarked beside them.

| File | What to show | Title | Description |
|---|---|---|---|
| `01-bags.jpg` | The combined bags with items from two or three sets, each in its colour, and unmarked items beside them | Your sets at a glance | Every item that belongs to an equipment set is framed and tinted in the set's colour. |
| `02-vendor.jpg` | A vendor's window open with the bags | Safe selling | Set items stand out before you sell anything. |
| `03-several-sets.jpg` | Close-up of an item in two sets, its border alternating the two colours, with the corner squares on | Items in several sets | The border alternates between the sets' colours, and each set adds a corner square. |
| `04-styles.jpg` | The same bag with only the corner squares, or only the border | Your style | Border, tint and corner squares, in any combination. |
| `05-options.jpg` | The options page (`/gsc`) | Options | Pick each set's colour, turn sets off, and choose how items are marked. |
| `06-equipment-manager.jpg` | The Character window's Equipment Manager with the colour squares on the set icons | Equipment Manager | Each set shows its colour. Click the square to change it. |

Rename or drop shots freely.
